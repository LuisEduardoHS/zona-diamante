# Bateador de la beta

Cuatro WebP proporcionados por el usuario para el Prompt 2 de Fase 4. Se copiaron íntegros, conservando RGBA, transparencia y lienzo original de 540×950. No son imágenes generadas ni recortadas/recomprimidas.

Secuencia inspeccionada: b1 reposo, b2 preparación, b3 swing, b4 seguimiento. `public/data/game-beta-art.json` configura rutas, desplazamientos del anclaje y tiempos; las imágenes mantienen escala uniforme y base de apoyo común. Las diferencias de postura del dibujo son intencionales. Se pueden reemplazar ajustando ese manifiesto, sin cambiar reglas del motor.
